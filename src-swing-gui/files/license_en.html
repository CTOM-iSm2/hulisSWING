PRIVACY POLICY

The HuLiS project team is committed to the protection of individual privacy and ensures that no personally-identifying information is collected nor distributed. In order to document the amount of use of HuLiS and to provide the best services to our users, we collects a minimal amount of non-personally identifying data upon each use. You can disable this at any time by the Files menu / Preferences / Privacy tab. The information collected are : connecting countries, type of use (web or standalone), Java localization, Java version, operating system, browser, version of HuLiS, starting time, error occurred, last action. Preferences are stored in the file user preferences used by Java-dependent system or in a web cookie. HuLiS automatically checks if a new version is available or if the current version is outdated. You can disable this functionality in the File menu / Preferences / Updates tab.
